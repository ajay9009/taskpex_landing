# TaskPex – Landing Page

> **Task • Earn • Grow** — Official landing page for the TaskPex Android app.

TaskPex is a free rewards app where users earn real coins by playing quizzes, spinning the wheel, scratching cards, solving word puzzles, and completing daily challenges — then convert those coins to UPI cash, gift vouchers, or mobile recharge.

---

## 🌐 Live Preview

Open `index.html` in any browser, or deploy via GitHub Pages / Firebase Hosting.

## 🎨 Design System

- **Theme:** Dark navy (`#0d0f1a`) with gold (`#f5c518`) and cyan (`#00d4ff`) accents
- **Fonts:** [Nunito](https://fonts.google.com/specimen/Nunito) (body) + [Orbitron](https://fonts.google.com/specimen/Orbitron) (display)
- **Animations:** Scroll-reveal, glowing background circles, animated spin wheel, hover lifts
- **Fully Responsive:** Mobile-first, works on all screen sizes

## 🚀 Deployment

### GitHub Pages
1. Go to **Settings → Pages**
2. Set source to `main` branch, root `/`
3. Site will be live at `https://<username>.github.io/taskpex_landing/`

### Local Development
Simply open `index.html` in a browser — no build step required.
